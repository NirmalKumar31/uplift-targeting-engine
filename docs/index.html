Who should get the promo SMS?

Causal uplift model on the X5 RetailHero randomised SMS experiment (400k loyalty clients). It ranks clients by how much the message changes their chance of buying and texts only where that pays for the SMS. Champion: S-learner, evaluated once on a locked test set of 40,008 clients.
